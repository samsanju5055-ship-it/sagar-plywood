# Sagar Plywood, Glass & Hardware

A responsive React website for the Sagar Plywood, Glass & Hardware store in Borabanda, Hyderabad.

## Run locally

1. Install [Node.js 20.19 or later](https://nodejs.org/).
2. In this folder, run `npm install`.
3. Run `npm run dev` and open the local address shown in the terminal.

## Create a production build

Run `npm run build`. The deployable files are created in `dist/`.

## Publish with Vercel

1. Create a GitHub repository and push this project (do not upload `node_modules`).
2. Sign in at [vercel.com](https://vercel.com/) with GitHub, then choose **Add New → Project**.
3. Import the repository. Vercel will recognize Vite automatically.
4. Keep the build command as `npm run build` and output directory as `dist`, then select **Deploy**.
5. Vercel will give you a public `*.vercel.app` URL. Add a custom domain from the project’s **Settings → Domains** when ready.

## Before publishing

- Check the phone number, hours and address against the business’s current details.
- Replace the two Unsplash background photographs in `src/styles.css` with images you own or are licensed to use.
- Add a domain name and a Google Business Profile link when available.
